# Retail Sales Analysis (EDA)

## 📌 Overview
Exploratory Data Analysis on retail sales data to uncover customer and product insights.

## 🗂 Dataset
- Source: Kaggle Retail Sales Dataset

## ⚙️ Workflow
1. Data Loading & Inspection
2. Data Cleaning (missing values, duplicates)
3. Outlier Detection & Treatment
4. Summary Statistics & Visualization

## 📊 Deliverables
- Cleaned dataset
- Data quality report
- 4–6 key visualizations

## 🛠 Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn
